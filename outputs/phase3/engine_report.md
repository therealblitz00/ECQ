# Phase 3: similarity engine report

Generated by `src/phase3_engine.py build` from `items_clean.parquet` (10,555 colourways).
Output: `data/processed/neighbours.parquet` (105,550 rows: query, rank, candidate, score, `sim_<block>`,
`contrib_<block>`) and its settings in `neighbours.json`.

## Settings

- Top-k: **10** per query (the brief asks for at least 4).
- Candidates: same CAT_DES_EN; the query itself and
  other colours of the same model (`PROD_REF` / `PROD_REF_EQUIV`) are excluded.
- Weights (`src/phase3_weights.json`, starting values for Phase 4). A pair is scored on the blocks both items
  have, and the weights are rescaled to sum to 1 over those blocks.

| Block | Weight | Items with the block |
|---|---|---|
| `image` | 0.30 | 9,445 |
| `categorical` | 0.30 | 10,555 |
| `text` | 0.10 | 10,555 |
| `composition` | 0.10 | 10,554 |
| `palette` | 0.10 | 9,445 |
| `numeric` | 0.10 | 10,555 |

The `image` block only uses photos with `img_trusted`, the `palette` block only photos with `img_colour_trusted`.
