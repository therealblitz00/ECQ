# Phase 4: interactive feedback report

Generated by `src/phase4_feedback.py fit` (2026-10-12) from
28 sorted queries (4 Manuel).

The reviewers drag each query's candidates into *Similar* (best first) or *Not similar*. Every similar item beats the
items below it and every "not" item; the six block weights are fitted to those preferences with a Bradley-Terry
model, pulled towards the starting weights (prior sd 0.5 on the log-weights). Candidates come from a fixed pool
(top 5 at image weights 0, 0.3, 0.6 + 2 random), shown shuffled and
blind, so the learned weights never change what a reviewer sees.
