# Phase 5: explanations of the similar products

Generated by `src/phase5_explain.py build` (2026-10-26): 10,555 products × top 5 = 52,775 explained matches.

## How an explanation is computed

The engine score is a weighted mean of block similarities, and each block is a dot product of unit-length rows split into named slices. So every explanation is an **exact decomposition** of the score (no surrogate model, no sampling, no LLM): the share of each block, then inside the blocks the shared attributes, the shared materials (rare materials weigh more) and the price / launch parts. Differences (price, colour with the measured closeness of the two colour names, finish, sub-family) and the shared dominant colours of the photos are added from the data.

## Checks

- **Completeness** (2,000 sampled pairs): the block contributions add up to the score up to 7.8e-07; the attribute parts add up to the categorical similarity up to 1.0e-07 (float32 rounding).
- **Cost**: 3.07 ms per explained match on a laptop CPU (52,775 matches in 162 s), so every product is explained in the batch run.
- **Faithfulness (deletion test)**: for the best match of random queries, one block is removed (weight 0) and the match's new rank is measured. Removing the block the explanation names **first** should move the match most:

| | mean | median | share no longer first |
|---|---|---|---|
| named first | 6.49 | 1.00 | 0.43 |
| named last | 1.41 | 1.00 | 0.21 |
| random | 2.47 | 1.00 | 0.38 |

- **Agreement with the team** (candidates sorted in the Phase 4 feedback app): mean block similarity of the candidates the team called *similar* vs *not similar*. A large standardised difference means the block separates what people see as similar, so it deserves its place in the explanation:

| | not similar | similar | difference | difference / sd |
|---|---|---|---|---|
| score | 0.561 | 0.792 | 0.231 | 1.362 |
| catalogue attributes | 0.411 | 0.744 | 0.333 | 1.344 |
| description | 0.672 | 0.854 | 0.182 | 1.089 |
| photo | 0.804 | 0.885 | 0.081 | 1.073 |
| materials | 0.503 | 0.778 | 0.276 | 0.789 |
| price and launch | 0.440 | 0.668 | 0.229 | 0.751 |
| photo colours | 0.372 | 0.512 | 0.139 | 0.352 |

- `outputs/phase5/brief_example.json`: the brief's example product, fully explained.
