# Phase 5: explanations of the similar products

Generated by `src/phase5_explain.py build` (2026-10-28): 10,555 products × top 5 = 52,775 explained matches.

## How an explanation is computed

The engine score is a weighted mean of block similarities, and each block is a dot product of unit-length rows split into named slices. So every explanation is an **exact decomposition** of the score (no surrogate model, no sampling, no LLM): the share of each block, then inside the blocks the shared attributes, the shared materials (rare materials weigh more) and the price / launch parts. Differences (price, colour with the measured closeness of the two colour names, finish, sub-family) and the shared dominant colours of the photos are added from the data.

## Checks

- **Completeness** (2,000 sampled pairs): the block contributions add up to the score up to 6.8e-07; the attribute parts add up to the categorical similarity up to 1.2e-07 (float32 rounding).
- **Cost**: 2.19 ms per explained match on a laptop CPU (52,775 matches in 116 s), so every product is explained in the batch run.
- **Faithfulness**, on the best match of random queries (scores rounded like the engine, ties counted against the match). *Deletion*: one block removed; for an additive score this mostly confirms the arithmetic. *Sufficiency*: only the two blocks the explanation names first are kept, i.e. the short explanation a buyer reads; is the match still in the top 5, compared with two random blocks, the two named last, and a control: the two blocks with the largest global weights. Most of the time the explanation names exactly those (photo + attributes), so the informative rows are the ones where it names other blocks than the control:

- `outputs/phase5/similar_products.csv`: the brief's format for every product (top 5, with the summary).
- `outputs/phase5/brief_example.json`: the brief's example product, fully explained.
